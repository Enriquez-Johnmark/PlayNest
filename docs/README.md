## Authority and originals

Latest explicit user decisions take precedence. PRODUCT.md owns product purpose and constraints; the mobile PRD owns detailed behavior and priority; DESIGN.md owns visual direction; the implementation plan owns sequencing. If these conflict, resolve and update the owning document before implementation.

[Original combined specification](PlayNest_AI_Coding_Agent_Specification.md) and [original design specification](PlayNest_DESIGN.md) are retained unchanged as historical source material. Their mixed mobile/web delivery requirements and three-day schedule do not override the active documents. Embedded FILE markers and [original documentation tree](PlayNest_Docs_Tree.txt) describe a proposed package, not files currently present.

The source's content seed remains useful for fictional activity descriptions, instructors, prices, and parent/child fixtures. It does not establish real commercial offers. Unchanged source details may be consulted where active documents are silent; conflicts and scope additions must be recorded rather than silently imported.
